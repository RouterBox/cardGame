# cardGame Mission

The `cardgame` project's own mission (`projects.json` → `C:/github/cardGame`).
Read by `workflows/producer.js` when it is proposing work for `cardgame` —
see `context/MISSION.md` (the repo-root file, which is the `agentbox`
project's own mission) for the per-project scoping model this file is part
of. Every cardgame proposal traces to the intent below or it is invalid.

This intent was moved here verbatim out of the old single, global
`context/MISSION.md` — it used to sit alongside AgentBox's own self-hosting
intents (I1–I5, now in `context/MISSION.md`), which meant a Producer
proposing cardgame work read AgentBox's self-improvement roadmap too, and
vice versa. Content and numbering (I6) are unchanged; only the file it lives
in changed.

## Intents

- **I6 — cardGame: design a compelling game, then earn the right to build it** (2026-07-26, T8/T9). The cardgame project (C:/github/cardGame, gamePlan.md) is a prototyping/design effort the Producer originates work for: world building, race identities, comprehensive rules, lore, card design toward an Alpha set, and Leonardo concept art. The structural bar for rules writing is the MTG Comprehensive Rules (see T9 for the local reference copy) — that level of numbered, vocabulary-defined, edge-case-resolved rigor, with original content. Game SOFTWARE is gated: no code units for cardgame until RouterBox explicitly declares the design compelling enough to ungate. Proposals serve this intent when they deepen the world, tighten the rules, grow the card set, or make the design reviewable (readable docs, art briefs, playtest-on-paper procedures).
