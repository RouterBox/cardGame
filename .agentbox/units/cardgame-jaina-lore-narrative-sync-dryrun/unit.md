## Intent

design/ideas-inbox.md's 2026-07-28 'use Jaina as the content backbone' directive asked structured game content to become schema-backed Jaina records. Cards, characters, races, star-atlas worlds, lore eras, Fount cosmology, and (as of the just-merged cardgame-jaina-world-narrative-sync-dryrun unit) world.md's free-form narrative prose all now have their own dry-run sync tool. design/lore.md's '## Summary' section is the one remaining orphaned prose section: lib/parse-lore-markdown.js's parseLoreMarkdown explicitly skips it (it only emits records for '## Timeline of Eras' and the numbered era sections it names), so it has never been represented in Jaina at all. Add lib/parse-lore-narrative-markdown.js exporting parseLoreNarrativeMarkdown(markdown) and loadLoreNarrativeSections(), following lib/parse-world-narrative-markdown.js's exact shape: use lib/markdown-sections.js's splitIntoH2Sections to find the 'Summary' H2 by exact title match, lib/markdown-sections.js's extractParagraph to build its body (joining the section's non-blank lines into one prose string), and lib/parse-card-markdown.js's slugify for the slug -- re-export all three by reference, do not reimplement any of them. Return exactly one record: { title: 'Summary', slug: 'summary', body }. Add tools/sync-lore-narrative-to-jaina.js mirroring tools/sync-world-narrative-to-jaina.js's structure precisely: import loadLoreNarrativeSections, define buildRecord(section) returning { title, slug, body }, define a NOT_IMPLEMENTED_MESSAGE naming 'Lore Narrative', and call lib/run-jaina-dryrun-cli.js's runDryRunSyncCli({ loadItems, buildRecord, notImplementedMessage, argv: process.argv }) instead of hand-rolling any dry-run control flow. Add one new bullet to design/DESIGN-READINESS.md Section 5's tooling list for the new tool, matching the existing bullet format and placement style used for the other sync-*-to-jaina.js entries, and extend Section 6 Gap 3's closing sentence to name design/lore.md's Summary section as now covered too, citing the new tool by filename. Touch no other line of DESIGN-READINESS.md (leave Section 4's art-brief-coverage sentence alone -- that belongs to a different open proposal). Do not touch design/lore.md itself, lib/parse-lore-markdown.js, lib/parse-world-narrative-markdown.js, lib/markdown-sections.js, lib/run-jaina-dryrun-cli.js, lib/parse-card-markdown.js, tools/sync-lore-eras-to-jaina.js, tools/sync-world-narrative-to-jaina.js, or any other existing tools/sync-*-to-jaina.js file or its test.
