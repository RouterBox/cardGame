## Intent

design/cards/alt-art-briefs.md implements the Alt-Art layer design/cards/card-anatomy.md's "The Layers" section defines: swap only the Art Window's illustration for an alternate illustration of the same subject matter, every other zone unchanged. It currently briefs the 5 alpha-set.md Fount Generators and the 5 character-signatures.md wave-1 cards — character-signatures-wave-2.md's 5 cards (Torel Ashgrave, Line-Captain of the Ember Vanguard, 2 Mass; Rathe Ossuary-Kin, Spore-Hound of the Sprawl, 3 Bloom; Doran Vex Amaranthine, Ledger-Warden of the Foreknowledge Archive, 2 Signal; Ysolde Thane, Pilgrim of the Unwritten Sign, 2 Tangle; Foreman-Prime Yssa Ductile, Keeper of the First Pattern, 4 Circuit), already fully briefed in art-briefs.md, have none. Add one new "###" section per wave-2 card to alt-art-briefs.md, appended after the existing 10 sections, using the identical Palette/Subject-Scene/Key-visual-elements/Composition template the file already establishes. Each Palette line must name the card-anatomy.md Fount-identity color matching that card's own Cost line, exactly as the base briefs already do: Torel Ashgrave -> Ash-grey, Rathe Ossuary-Kin -> Green, Doran Vex Amaranthine -> Cyan, Ysolde Thane -> Violet, Foreman-Prime Yssa Ductile -> Copper. Each Subject/Scene must describe a genuinely different moment than that card's base brief (mirroring the wave-1 alt pattern of shifting to before/after/private/aftermath rather than the base brief's active moment) so it satisfies test/design-alt-art-briefs.test.js's own word-overlap check once extended: e.g. Torel Ashgrave before she commanded the line rather than leading the formation; Rathe Ossuary-Kin in the Sprawl's quiet aftermath rather than mid-wound; Doran Vex Amaranthine cataloguing his own already-gathered ledger rather than actively reading an opponent's Archive; Ysolde Thane on pilgrimage before any Archive-reading rather than mid-working; Foreman-Prime Yssa Ductile at the First Pattern's founding moment rather than mid-production. Extend test/design-alt-art-briefs.test.js's EXPECTED_TITLES array to include the 5 new titles (10 -> 15) — its existing AC1 (section-shape) and AC2 (Subject/Scene overlap-vs-base) tests already generalize over EXPECTED_TITLES with no other code change needed. Do not touch character-signatures-wave-2.md, art-briefs.md's existing content, card-anatomy.md, or any of the 10 existing alt-art-briefs.md sections — this unit only appends 5 new sections and extends one array in the existing test file.
