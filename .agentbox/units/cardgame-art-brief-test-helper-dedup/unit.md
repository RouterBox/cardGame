## Intent

test/design-art-briefs.test.js (shipped) enforces T8's art-briefs-precede-art rule by checking, per card, that art-briefs.md contains a matching '###' section whose Palette line names the correct Fount-driven color, whose Key-visual-elements list is card-specific rather than generic filler, and whose Composition line references an aspect ratio — logic written once, inline, when the file covered only alpha-set.md, and widened in place (not duplicated) when frontier-set.md and character-signatures.md were added by the shipped cardgame-art-briefs-frontier-signatures unit. That inline-widening approach breaks down once units need their own, non-conflicting test files for concurrent bolting: the open cardgame-art-briefs-character-signatures-wave-2 and cardgame-art-briefs-wormhole-restrictions proposals each describe adding a brand-new test file that re-implements this exact same three-part check by hand, precisely the copy-paste-under-parallelism pattern T11 already flagged once and that the currently-bolting cardgame-card-template-test-helper-dedup unit is independently fixing for a different duplicated check (Section 9.1 card-template ordering) on a different file family (design-cards.test.js/design-frontier-cards.test.js/design-signature-cards.test.js) — confirming this is a recognized, recurring shape rather than premature abstraction. This unit extracts the Palette/Key-visual-elements/Composition check out of test/design-art-briefs.test.js into a new test/helpers/art-brief.js (mirroring the existing test/helpers/markdown.js and the in-flight test/helpers/card-template.js precedents) as a single exported function, and updates test/design-art-briefs.test.js to call it instead of defining its own copy. It does not touch or rewrite the wave-2 or wormhole-restrictions proposals' not-yet-created test files — those remain free to either adopt the helper or land as filed, since they are outside this unit's scope — and it does not touch any design/*.md content, art-briefs.md, or the compositing/rendering code itself; only test/design-art-briefs.test.js changes and test/helpers/art-brief.js is added.

## Acceptance Criteria

- AC1 [paraphrase]: test/helpers/art-brief.js exists and exports a function that, given a card's title, body text, and the art-briefs.md text, registers node:test assertions for: an exact-title matching '###' brief section exists; its Palette line names the Fount color from card-anatomy.md's Fount identity table matching the card's own Cost line; its Key-visual-elements list has at least 2 bullets sharing at least 2 significant words with the card's own rules/flavor text; its Composition line references an aspect ratio.
- AC2 [paraphrase]: test/design-art-briefs.test.js no longer contains its own inline implementation of the Palette/Key-visual-elements/Composition check — it calls the shared helper from test/helpers/art-brief.js instead, for every card it currently covers (alpha-set.md, frontier-set.md, character-signatures.md).
- AC3 [inferred] (held_out): Running `node --test` produces the same number of passing and failing tests for test/design-art-briefs.test.js after the refactor as it did before, run against the current unmodified design/cards/*.md and art-briefs.md content.
- AC4 [inferred]: No file under design/ is modified by this unit and no other existing test file is touched — git diff is limited to test/design-art-briefs.test.js (modified) and test/helpers/art-brief.js (added).
