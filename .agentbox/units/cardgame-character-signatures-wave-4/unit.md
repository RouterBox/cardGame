## Intent

design/cards/character-signatures.md, -wave-2.md, and -wave-3.md each sign 5 named characters (one per race) from design/characters/*.md, using the canonical rules.md Section 9.1 template (Name, Cost line, Type line, Rules text, optional Stats/counters line for Permanents) and citing both the race and the character by name in the card's Rules text/flavor text so the cross-reference is checkable, exactly as design/DESIGN-READINESS.md Section 2 already documents. Each race file under design/characters/ names exactly 4 characters; waves 1-3 have together signed 3 of each race's 4, leaving exactly one unsigned character per race: Karrow Vantiss, Orphan of the Ninth Cinder (Cindral Reach); Nyth Corrow, The Shrine-Grown (Mireth Bloom); Yuen Ashcroft, Vantage-Clerk of the Dead Drop (Panoptic Concord); Wren Sable-Vow, Oath-Sworn of the Standing Stones (Starweave Communion); Vantel Ninth-Chorus, Iron-Choir Enforcer (Wrought Assembly). Add design/cards/character-signatures-wave-4.md with exactly 5 new '###' cards, one per race, each naming that race's own remaining character above, following the identical Cost-line/Type-line/Rules-text/flavor-text template and file structure (H1 title, '## Summary', then one '## The <Race> — <Domain>' H2 per race containing that race's card) that character-signatures-wave-3.md already establishes. Add one new bullet to design/DESIGN-READINESS.md Section 3 citing character-signatures-wave-4.md by filename, in the same list-item style the 10 existing card-set bullets use (satisfies test/design-readiness.test.js's existing disk-derived AC3/AC6 citation check, which fails the suite if any real design/cards/*.md file goes uncited) — touch no other line, section, or file: not Section 4, Section 5, Section 6, design/cards/art-briefs.md, design/cards/alt-art-briefs.md, character-signatures.md, character-signatures-wave-2.md, character-signatures-wave-3.md, or any design/characters/*.md file. Regenerate site/ via tools/build-site.js. Add a new, independent test/design-signature-cards-wave-4.test.js mirroring test/design-signature-cards-wave-3.test.js's exact structure: AC1 (file exists, exactly 5 distinct cards, one per race), AC3 (no name/character collision against wave-1/2/3 combined, plus a new completion check that across all four files every one of the 20 design/characters/*.md entries is named by exactly one card total), AC4 (Cost-line Fount and Type-line domain/Permanent checks per race), AC5 (site HTML exists; character-signatures.md, -wave-2.md, -wave-3.md, and every design/characters/*.md file still exist, are non-empty, and still parse).
