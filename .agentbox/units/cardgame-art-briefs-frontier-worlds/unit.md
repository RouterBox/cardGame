## Intent

design/cards/art-briefs.md documents an art brief for every card in every shipped card set so tools/composite-card-art.js has an input for each — DESIGN-READINESS.md Section 6's Open Gap 1 already closed this exact class of hole twice (wormhole-closure-cards.md, spatial-race-identity-set.md), each time by appending one brief per card in the established Palette/Subject-Scene/Key-visual-elements/Composition format. design/cards/frontier-worlds-set.md (5 cards: Halvorne Reclamation Fleet — Cindral Reach, 2 Mass, Materials-Permanent; Tanglekeeper's Vigil — Starweave Communion, 2 Tangle, Magic; Kelmourn Wreck-Bloom — Mireth Bloom, 2 Bloom, Biology-Permanent; Kelmourn Claim Ledger — Panoptic Concord, 1 Signal, Intelligence; Tallowfen Chokepoint Works — Wrought Assembly, 2 Circuit, Technology-Permanent) shipped this session and has never been briefed. Add one new '###' section per card to design/cards/art-briefs.md, appended after the file's existing final section, using the identical template every prior art-briefs unit used. Each Palette line must name the card-anatomy.md Fount-identity color matching that card's own Cost line, exactly per the mapping above. Each brief's Key visual elements must draw at least 2 concrete words from that card's own Rules text/Type line (mirroring test/design-art-briefs.test.js's AC2 overlap check), grounded in each card's own named world (Halvorne Junction, Kelmourn Drift, Tallowfen from design/star-atlas.md) and Section 8.3/8.6 mechanic (Contested Discovery, Frontier Discovery, Neutral Planet, Blockade) rather than generic filler. Each Composition line must reference the Art Window's rectangular/landscape shape and aspect ratio (mirroring the '5:3'-style note every existing brief uses). Update design/DESIGN-READINESS.md Section 4's coverage sentence to add 'frontier-worlds-set.md' to the list of files art-briefs.md covers, and update Section 3's 'Total: 59 named cards' sentence's cross-reference if it names art-briefs.md's section count (leave the live-derived test assertions in test/design-readiness.test.js untouched — they already re-derive counts from disk). Do not touch frontier-worlds-set.md itself, card-anatomy.md, alt-art-briefs.md, or any of art-briefs.md's 59 pre-existing sections. Add a new, independent test/design-art-briefs-frontier-worlds.test.js mirroring test/design-art-briefs-spatial-race-identity.test.js's exact structure (AC1 section-shape/uniqueness, AC2 palette-color-and-visual-overlap, AC3 composition-aspect-ratio), scoped to frontier-worlds-set.md's 5 cards only.
